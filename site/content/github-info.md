## Recent updates

- **Issue statuses and repository boards (public preview):** Issues can now carry more specific statuses than open or closed, giving your team and agents shared context on what is in flight. Source: [GitHub Changelog, Nov 23, 2026](https://github.blog/changelog/2026-11-23-issue-statuses-and-repository-boards-are-in-public-preview/).
- **Copilot code review billing defaults to the organization:** If you haven't chosen how to bill Copilot code review for licensed members, reviews will be billed to your organization starting December 30, 2026. Source: [GitHub Changelog, Nov 25, 2026](https://github.blog/changelog/2026-11-25-copilot-code-review-billing-will-default-to-the-organization/).
